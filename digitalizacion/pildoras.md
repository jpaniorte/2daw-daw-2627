# Píldoras de Digitalización

## Normas

- Después de escuchar cada píldora, y cuando el alumno lo considere, puede solicitar hacer un control tipo test de 10 preguntas sobre esa píldora durante la hora de Digitalización (apto con más de 5 aciertos).
- Durante la escucha de la píldora, el alumno puede ir tomando apuntes en un folio en blanco. Durante la realización del control puede hacer uso de este folio en blanco. Se recomienda que los estudiantes se organicen para poder cubrir el máximo de píldoras y compartir estos folios de apuntes entre ellos.
- No hay orden: el alumno elige con qué píldora empezar y cuál quiere que se le evalúe, según sus preferencias. Fecha límite para hacer el control: **5 de febrero**.
- Las notas de los controles aparecerán en **"Qualificacions"** de Aules.
- Se debe superar al menos el **50% de las píldoras (37 aptos)** para poder evaluar esta sección.
- Estas píldoras suponen el **60% de la nota final**.
- El otro 40% de la nota será la media de controles y prácticas.

<p class="pildoras-note">El botón "Marcar como completada" guarda el estado únicamente en este navegador (no sustituye al control ni se envía al profesor); sirve solo para que lleves tu propio seguimiento.</p>

<script>
(function () {
  var STORAGE_KEY = "pildoras-completadas";

  function getCompleted() {
    try {
      return JSON.parse(localStorage.getItem(STORAGE_KEY)) || [];
    } catch (e) {
      return [];
    }
  }

  function setCompleted(ids) {
    try {
      localStorage.setItem(STORAGE_KEY, JSON.stringify(ids));
    } catch (e) {}
  }

  function refresh(btn) {
    var id = btn.getAttribute("data-pildora");
    var done = getCompleted().indexOf(id) !== -1;
    btn.classList.toggle("done", done);
    btn.textContent = done ? "✓ Completada" : "Marcar como completada";
  }

  document.querySelectorAll(".pildora-complete-btn").forEach(function (btn) {
    refresh(btn);
    btn.addEventListener("click", function () {
      var id = btn.getAttribute("data-pildora");
      var completed = getCompleted();
      var idx = completed.indexOf(id);
      if (idx === -1) {
        completed.push(id);
      } else {
        completed.splice(idx, 1);
      }
      setCompleted(completed);
      refresh(btn);
    });
  });
})();
</script>
